# Decky CustomCloud

This plugin allows for syncing your config and save data to the cloud, using rclone, which means it works with OneDrive, Google Cloud, Dropbox and more (or at least it will once rclone is actually implemented). But unlike [SDH-GameSync](https://github.com/AkazaRenn/SDH-GameSync) and [Decky Ludusavi](https://github.com/GedasFX/decky-ludusavi), this plugin keeps config and save data for each game separate and in simplified folders, rather than copying the entire path one-to-one.

Moreover, this is meant to be used with games that do not support Steam Cloud or that you do not have Steam Cloud enabled for, though this plugin will allow for backing up those other games as well (though restoring from those backups might not be recommended as they may clash with Steam Cloud).

Defaults for each game are loaded from the [Ludusavi Manifest](https://github.com/mtkennerly/ludusavi-manifest) from mtkennerly. An Internet connection is required to download the manifest, at least the first time. It also has some support for non-Steam shortcuts, with the possible exception of handling files within the game's installation path itself. With shortcuts, it searches the manifest for the given shortcut name, though even that can fail if there isn't an exact match.

Basic rclone configuration should be doable from the Quick Access Menu. Advanced configuration options will likely throw an error due to unknown "types". I probably wouldn't even know what to do with most of them, if the output from `rclone config providers` is anything to go by.

Though this could be made to work with Windows with some tweaking, the main focus for this is for the Steam Deck. Currently, there are no means of having different OSs directly sync through this plugin. One possible workaround for Windows, if your backend supports local access, is to set up a symlink between the file/folder on the remote and the local config or save path, though admittedly this would be much harder to set up if the game saves config or save data as a bunch of files or folders in a folder alongside a bunch of other unrelated files (such as Unreal 1 or System Shock 2).
